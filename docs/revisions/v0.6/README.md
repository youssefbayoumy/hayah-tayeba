# v0.6 — Three gardens and original client artwork

23 October 2026 · Arabic browser preview · Children aged 10–14.

This implements the approved replacement plan. It supersedes the twelve-stage Tazkiya curriculum in [v0.5](../v0.5/README.md). Dhikr keeps its four-stage opening sample; the visual theme changes across the whole demo. The frozen v0.3 package and previous PDFs/handoff ZIPs are preserved.

## Confirmed experience

- Two main journeys remain: Dhikr and the journey of the good heart. The second contains **التخلية → التحلية → التزكية**, five challenges each.
- Images 1–3 supplied on 23 October define the fifteen questions and three options each. Image 4 is a visual reference only. Obvious grammar/pronoun errors are corrected, including the broken-vase prompt.
- Original scene crops, vivid pink actions, parchment/wood panels and green/purple garden identities replace the previous softer theme throughout welcome, setup, maps, Dhikr, diary, profile and settings.
- A child may explore **any answer**, see its explanation and continue. There are no wrong-answer penalties or lost hearts. Progress measures exploration, not correctness or spirituality.
- Five challenges earn one garden key. The next garden unlocks; three keys open **كنز القلب الطيب**. Replays do not duplicate keys or progress.
- The same original video remains: 0–55 seconds before التخلية, 55–115 before التحلية, 115–end before التزكية. Completed viewing records remain valid.
- Optional private writing and optional seven-day practice remain available. The plan editor is independent of the retired stage 12.

## Data and review evidence

Learner schema 3 upgrades both the original flat state and v0.5/schema 2. Existing Dhikr progress, character, nickname, video positions, diary and practice plans remain. The old twelve-stage progress/keepsakes appear under **رحلتك السابقة**. New challenges start fresh. Old draft-only and saved writings retain their original labels and can be edited/deleted. Individual deletion removes associated raw migration backups; reset clears current data and both backup versions.

## Delivery boundary

This is the updated static web prototype, using local browser storage. It needs internet for initial files/video, has no login or backend, and is not the installed Expo application. Original collage crops retain their supplied resolution; no AI reconstruction or synthetic detail is added. Final curriculum approval, full video captions, testing with children and native offline/device QA remain product-release work.
